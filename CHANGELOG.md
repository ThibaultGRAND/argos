First public version (V1 of the plan: read, then act).

### Added
- Claude Code history by project, imported in the background, with full-text search (⌘K).
- Session report: Markdown, syntax highlighting, grouped tool calls, “Open in VSCode”.
- Run and drive Claude Code sessions from Argos: live output, permission cards, pause and stop.
- Changes made by the agent, kept apart from your own edits; undo a file, a turn or the whole session (always undoable).
- PR-style review: whole session, since your last review or one turn; line comments sent back to the agent;
  per-file “Reviewed” checkboxes.
- Context gauge with per-category details and plan usage (5-hour and weekly limits).
- System notifications when an agent waits for you, finishes or fails.
- Settings: theme, language (French, English), editor, notifications, updates.
- Installers for macOS, Windows and Linux on GitHub Releases, with update checks.
